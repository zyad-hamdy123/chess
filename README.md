# D.zyad Chess

Android chess app with live Stockfish analysis (best move arrows, eval bar, game review, play vs engine).

- App: `chess-light.apk` (package `com.zyad.chlte`, v1.6.0, about 2.8 MB)
- Website: https://zyad-hamdy123.github.io/chess/

## Source and license

This app uses the Stockfish chess engine, which is licensed under GPL-3.0. This repository is therefore released under GPL-3.0 (see LICENSE). Stockfish: https://stockfishchess.org

The source in `chess-source.zip` contains the web part of the app (HTML, JavaScript, CSS). The Java source of the Android wrapper was not recovered, so it is not included.
